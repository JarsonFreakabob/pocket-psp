A few things to know.

How do saves work?

In-game saves use the emulated PSP memory stick. Pocket mirrors it to browser storage while you play and before you quit. Save states capture the running emulator and use three slots per game. Save inside your game too: states can depend on the emulator version.

What can I play?

PSP games you have permission to use and PSP homebrew. PS1 EBOOTs, PS2, and Vita games are not supported. Encrypted or corrupted game files may not launch.

Why does the page reload on the first launch?

GitHub Pages needs a small service worker to enable the browser isolation required for PSP emulation. One setup reload is expected. If launch fails, use the player diagnostics and try current Chrome or Edge.

Can I move my games or saves to another browser?

Export a backup from Memory stick, then restore it in the other browser. Add the same game files there to reconnect their state slots. Game files are not included in backups.

What are the keyboard controls?

The emulator's controller menu shows and remaps every input. Default mappings commonly use arrows for the D-pad, Z/X/A/S for face buttons, Q/W for shoulders, and Enter for Start. Use the core's controls panel as the source for your active mapping.
