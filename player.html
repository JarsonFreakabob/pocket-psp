A memory stick, minus the plastic.

Save from inside a game just as you would on a PSP. Pocket copies the entire PSP memory stick into its local database every 15 seconds and when you choose Save & quit.

Save states freeze the current session in one of three slots. Save & quit preserves in-game saves; use Save state first if you want to resume at an exact moment.

Use Export backup in your library for a downloadable copy of your saves and states. Clearing site data or using private browsing can remove local progress. Games and saves are not uploaded to GitHub.
